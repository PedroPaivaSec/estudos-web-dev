# 📓 Meus Estudos de PHP

Este repositório foi criado para centralizar e organizar todos os meus exercícios, códigos de teste e projetos de estudo focados no aprendizado da linguagem **PHP**. 

O objetivo aqui é documentar a minha evolução técnica de forma gradual, saindo da base estruturada da web dinâmica, passando pela Orientação a Objetos, até chegar no entendimento de frameworks modernos como o **Laravel**.

---

## 🗺️ Trilha de Aprendizado

Organizei o repositório para acompanhar o meu progresso prático nos conceitos da linguagem:

- [x] **Fase 1: PHP Estruturado & Web Dinâmica**
  * Manipulação de formulários (`$_POST` e `$_GET`).
  * Conexão com banco de dados via **PDO (PHP Data Objects)** e consultas seguras com *Prepared Statements*.
  * Controle de estado e persistência de dados em múltiplas páginas com `$_SESSION`.
- [ ] **Fase 2: PHP Orientado a Objetos (POO)**
- [ ] **Fase 3: Ecossistema de Frameworks (Laravel)**
